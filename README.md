# My Launchpad Site 123

A starter project scaffolded by [Launchpad AI](https://launchpad.ai) — your guided path to building on Netlify.

## What's in here

- **Vite + React 19 + TypeScript** — front-end framework and tooling.
- **Tailwind v4** — CSS via the official Vite plugin.
- **netlify.toml** — build settings and a functions directory (empty for now).

## Next steps

Head back to Launchpad and let your instructor guide you in extending this project — adding a serverless function, AI inference, and more.

## Local development

```bash
npm install
npm run dev
```

Then visit http://localhost:5173.

## Deploying

This site is auto-deployed to Netlify whenever you push to the default branch. See your site in the Netlify dashboard.
